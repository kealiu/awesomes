## 关于

本项目旨在整理 GitHub 上高质量的 Awesome 清单，方便开发者一站式检索。欢迎提交 PR 补充更多优质资源。

### 如何贡献

- 新增条目需是 GitHub 上真实存在、有一定社区活跃度的仓库
- 请将条目放入合适的分类，如无合适分类可新建
- 说明需简洁准确
